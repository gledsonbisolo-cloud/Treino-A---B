TREINO A + B — PWA PARA IPHONE

1. Publique esta pasta em um endereço HTTPS (por exemplo, GitHub Pages, Netlify ou outro serviço de hospedagem estática).
2. Abra o endereço no Safari do iPhone.
3. Toque em Compartilhar.
4. Escolha “Adicionar à Tela de Início”.
5. Abra pelo novo ícone. O app funcionará em modo de tela cheia e poderá funcionar offline depois do primeiro carregamento.

IMPORTANTE: o iPhone não permite instalar um PWA completo a partir de um arquivo HTML local (file://). É necessário abrir o app por HTTPS para o Safari reconhecer o manifesto e o Service Worker.
