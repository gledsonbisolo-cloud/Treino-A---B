# Treino A/B — PWA para iPhone

Aplicativo web instalável com os treinos A e B, imagens dos equipamentos, checklist funcional e cargas editáveis.

## Publicar com GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)** e salve.
4. Depois que o GitHub Pages publicar, abra o endereço do site no Safari do iPhone.

## Instalar no iPhone

No Safari, abra o endereço publicado, toque em **Compartilhar** e selecione **Adicionar à Tela de Início**.

## Recursos

- Treinos A e B em abas separadas.
- Checklist de 10 exercícios em cada treino.
- Progresso salvo no navegador.
- Cargas editáveis com salvamento local.
- Arquivos e imagens preparados para cache offline via Service Worker.

**Observação:** a primeira abertura precisa de internet para baixar os arquivos e armazená-los para uso offline. A disponibilidade da publicação depende da ativação do GitHub Pages nas configurações do repositório.
